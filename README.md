## Project Overview
This project introduces a novel generative modeling framework for time-series data that represents sequences as images. The proposed method effectively handles both short and long sequences and supports diverse tasks, including unconditional generation, interpolation, and extrapolation. By leveraging invertible transforms such as delay embedding and the short-time Fourier transform , we construct a unified framework that can process variable-length time series with high efficiency and accuracy.

We provide a requirements.yaml file to easily create a Conda environment configured to run the model:
```bash
conda env create -f requirements.yaml
conda SCNU_Ti
```
